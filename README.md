# Chinda ✦

A cute anime-inspired English and date-roleplay practice app for adults (18+). Choose a fictional adult character, read their interests, pronouns, individual communication preferences, and boundaries, then rehearse a date. Includes male, female, and non-binary characters, including two autistic adults with different preferences.

Choose everyday dates, flirting, or opt into the intimacy and consent topic. The latter includes non-graphic sexual-health conversation prompts, sexual slang, and a labeled vulgar example to avoid. Small flame markers distinguish flirty language, intimate/suggestive language requiring a context check, and boundary-crossing language that needs to stop. Flames describe words in context, never diagnoses or people, and are not progression levels.

The English phrase library explains meaning, register, context, and alternatives. Its interactive context checks use curated explanations; they do not assess a learner's own speech. The respect guide covers pronouns, neurodivergent communication preferences, individual choice, and consent.

The pink visual theme uses original decorative SVGs: Japanese-inspired sakura and wave patterns, Tibetan-inspired geometric woven borders, and Himalayan mountain silhouettes. The artwork is decorative; it does not change the lessons or use religious text. Static hosting should include `index.html`, `style.css`, `theme.css`, `app.js`, and the `assets` directory.

Run `npm run dev` from this directory. The app serves on port 3000. Python 3 is required; there are no package dependencies or build steps.

This is solo or partner practice: it does not record speech, generate character responses, assess language, or send messages. Rehearsal notes remain in memory between steps for each character/scenario and clear on reload. No backend, credentials, or persistent user storage are required. The app identifies its adult audience but does not implement age verification.
